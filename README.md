# qa_python

* test_add_new_book_add_two_books — проверка добавления двух книг в коллекцию (контроль размера словаря)
* test_add_new_book_add_specific_book — проверка корректности названия добавленной книги
* test_add_new_book_for_children — параметризованный тест проверки доступности книги с определенным жанром для детей
* test_new_book_without_genre — проверка, что у только что добавленной книги жанр по умолчанию остается пустым
* test_adding_specific_genre_2_genres_1_book — проверка фильтрации и получения списка книг по конкретному жанру
* test_add_in_favorites — проверка успешного добавления книги в список избранного
* test_delete_from_favorites — проверка корректного удаления книги из списка избранного
* test_geting_genre_by_name — параметризованный тест проверки получения жанра книги по её названию.
